# FEAT-015 — Phaser preview

Protótipo opcional Meteor Strike usando Phaser 3.90.0 via CDN versionada, cena, sprites SVG existentes, tweens e efeitos. Núcleo educacional e placar permanecem no HTML. Canvas padrão e fallback. Sem alteração do backend ou dependências npm. Migração para TypeScript/Vite, assets profissionais, testes Playwright e validação WebGL real são etapas posteriores. A CDN é carregada somente quando o usuário ativa o modo experimental; rede externa necessária. Não publicar como qualidade final.
